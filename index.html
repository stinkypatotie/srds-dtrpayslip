📋 Firebase Realtime Database Rules

Copy and paste these rules into your Firebase Console → Realtime Database → Rules. This opens the single shared sales_reports node used by every device — no token to keep in sync.

{
  "rules": {
    "YOUR_TOKEN_HERE": {
      ".read": true,
      ".write": true
    }
  }
}

This rule set is fixed — you only need to paste it into Firebase once.
